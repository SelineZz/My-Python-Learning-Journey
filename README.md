# 玫瑰花颜色寓意查询程序

## 一、项目简介

本项目是一个基于 Python 编写的简单交互式程序，主要用于查询不同颜色玫瑰花所代表的含义。

在日常生活中，不同颜色的玫瑰通常具有不同的象征意义。本程序通过获取用户输入的玫瑰花颜色，利用条件判断识别用户选择的颜色，并输出相应的花语及其含义，帮助用户了解不同颜色玫瑰所表达的情感，为选择和赠送玫瑰提供参考。

目前程序支持查询五种颜色的玫瑰：黄色、白色、红色、粉色和蓝色。如果用户输入的颜色不在支持范围内，程序会给出相应的提示信息。

## 二、文件说明

本项目目前包含两个 Python 文件：

1. **meaning.py**

   主要功能文件，定义了 `meaning()` 函数。该函数通过 `input()` 获取用户输入的玫瑰花颜色，利用条件判断识别不同颜色，并通过 `print()` 输出对应的花语及其含义。对于暂不支持的颜色，也设置了相应的提示信息。

2. **test_meaning.py**

   函数调用文件，主要用于运行和测试 `meaning.py` 中定义的函数。通过 `import meaning as mn` 导入 `meaning` 模块，并使用 `mn.meaning()` 调用其中的函数，实现程序的运行。

## 三、代码说明

本程序主要运用了函数定义、模块导入、用户输入和条件判断等 Python 基础知识。

1. **函数定义与模块导入**

   在 `meaning.py` 中，使用 `def meaning():` 定义函数，将玫瑰花颜色查询的相关代码封装在函数中，便于后续调用和重复使用。

   在 `test_meaning.py` 中，通过 `import meaning as mn` 导入模块，并使用 `mn.meaning()` 调用函数，实现功能文件与运行文件的分离。

2. **获取用户输入**

   使用 `input()` 函数获取用户输入的玫瑰花颜色，并将输入内容赋值给变量 `color`，作为后续条件判断的依据。

3. **条件判断**

   使用 `if...elif...else` 语句对用户输入的颜色进行判断，通过 `==` 运算符比较输入内容与预设颜色是否相符。

   - 当输入为“黄色”时，输出黄玫瑰代表的友谊、祝福和快乐等含义。
   - 当输入为“白色”时，输出白玫瑰代表的纯洁、天真、尊敬和怀念等含义。
   - 当输入为“红色”时，输出红玫瑰代表的热烈的爱和浪漫等含义。
   - 当输入为“粉色”时，输出粉玫瑰代表的初恋、心动、温柔和感激等含义。
   - 当输入为“蓝色”时，输出蓝玫瑰代表的奇迹、独一无二和珍贵的爱等含义。
   - 当输入不属于以上五种颜色时，执行 `else` 语句，输出提示信息。

4. **程序运行**

   确保 `meaning.py` 和 `test_meaning.py` 保存在同一文件夹中，运行 `test_meaning.py` 即可调用 `meaning()` 函数。根据程序提示输入对应的中文颜色，即可获得查询结果。
